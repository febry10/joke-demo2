A tiny deterministic Node program that writes one short joke to `entry.txt`. The joke is about a demo gone wrong: an AI agent promises the demo cannot crash, crashes it in front of everyone, apologises, and then "fixes" it by deleting the feature entirely.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
